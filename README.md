# Professional Data & Software Engineering Portfolio

Welcome to my personal portfolio! This project showcases my journey as a Software Engineer and Data Engineer, highlighting my technical expertise, featured projects, and professional certifications.

## 🚀 Live Demo
**[https://portfolio-033.vercel.app/](https://portfolio-033.vercel.app/)**

## 🛠️ Technical Stack
- **Frontend**: React 19, Framer Motion (for smooth animations), CSS3 (Vanilla)
- **Design**: Modern Glassmorphism, Responsive Layouts, Dynamic Interaction
- **Deployment**: Vercel

## 📂 Project Structure
- `frontend/`: The core React application source code.
- `frontend/src/App.jsx`: Main application logic and content.
- `frontend/src/App.css`: Custom professional styling system.

## 🌟 Key Features
- **Dynamic Project Gallery**: Interactive, drag-to-scroll project cards with "Tech Stack" flip-side details.
- **Certification Showcase**: Full-screen modal previews for professional credentials.
- **Responsive Design**: Optimized for desktop, tablet, and mobile viewing.
- **Direct Contact**: Integrated email and LinkedIn connectivity.
